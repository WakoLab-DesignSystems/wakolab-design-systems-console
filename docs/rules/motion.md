# Motion

- Duration: 100 ms (`--wl-motion`, from `--wl-dur-fast`), ease-out. No hover lift.
- Dialogs and toasts rise into place (opacity and a small translation). Skeletons shimmer while loading.
- **Reduced motion:** inside the Console root, animations and transitions are removed (durations reduced to 0.01 ms) and skeleton shimmer is hidden. The host page is not affected.
