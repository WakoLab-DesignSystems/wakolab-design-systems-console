## Not included

- **Icon artwork.** The frontend's icon path data has unresolved provenance (standard EXTRACTION_MATRIX §10, E4) and is not copied. Consumers supply their own icon set through `ConsoleRoot`'s `icons` prop; see the README.
- **Example and test assets.** `examples/public/design/logo/*.svg` are original synthetic files. The example font file `examples/public/design/fonts/example-sans.woff2` is not committed: the example's Vite configuration copies it from the declared `@fontsource-variable/dm-sans` package (OFL-1.1) when it starts.
- **Development tools** (React, Vite, TypeScript, Playwright, axe-core, PostCSS and others) are declared in `package.json` and keep their own licences; they are not shipped in `dist/`. React and React DOM are peer dependencies supplied by the consumer.
